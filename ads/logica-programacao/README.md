# Lógica e Programação

Materiais da disciplina de Lógica e Programação, organizados em módulos progressivos.

## Conteúdos

- **Módulo 01 — HTML e CSS:** estrutura de páginas, semântica, formulários e estilização.
- **Módulo 02 — JavaScript:** lógica, funções, eventos, DOM e interatividade.
- **Módulo 03 — PHP:** programação no servidor, formulários, banco de dados e CRUD.
- **Avaliações:** materiais utilizados na verificação da aprendizagem.

## Utilização

Siga os módulos na ordem indicada. Projetos front-end podem ser executados com Live Server; exemplos PHP exigem um servidor compatível, como XAMPP ou PHP Development Server.
