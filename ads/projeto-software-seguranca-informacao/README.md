# Projeto de Software e Segurança da Informação

Materiais da disciplina organizados por período letivo, com exemplos em Java, Programação Orientada a Objetos, banco de dados e desenvolvimento de aplicações.

## Organização

- `2025/`: materiais utilizados durante o ano letivo de 2025.
- `2026/`: materiais utilizados durante o ano letivo de 2026.

## Conteúdos

Fundamentos de Java, estruturas de controle, POO, encapsulamento, coleções, tratamento de exceções, JDBC, Spring Boot e segurança da informação.

Consulte os arquivos de cada aula e o `pom.xml` quando o projeto utilizar Maven.
