# UMC — Materiais dos Cursos de Graduação

Este repositório reúne materiais didáticos, exemplos de código, exercícios, projetos e recursos utilizados nas disciplinas de graduação ministradas pelo professor **Pedro Henrique Miho de Souza** na Universidade de Mogi das Cruzes (UMC).

## Organização

Os conteúdos estão agrupados por curso, disciplina e, quando disponível, ano ou semestre letivo.

```text
UMC/
├── ads/
│   ├── logica-programacao/
│   ├── projeto-software-seguranca-informacao/
│   └── software-basico/
├── engenharia-software/
│   ├── desenvolvimento-aplicacoes/
│   └── software-corporativo/
├── sistemas-informacao/
│   └── programacao-internet/
├── recursos/
│   ├── tabelas/
│   └── modelo-apresentacao.pptx
├── .gitignore
├── LICENSE
└── README.md
```

Cada disciplina possui um README próprio com a descrição dos conteúdos e orientações de utilização.

## Áreas abordadas

- Lógica de programação
- HTML, CSS, JavaScript e PHP
- Java e Programação Orientada a Objetos
- Dart e desenvolvimento de aplicações
- Banco de dados, JDBC e persistência
- APIs REST e Spring Boot
- Tratamento de erros e Spring Security
- Engenharia e projeto de software

## Como utilizar

```bash
git clone https://github.com/PedroMiho/UMC.git
cd UMC
```

Acesse a pasta do curso e consulte o README da disciplina desejada. Projetos Java com `pom.xml` normalmente podem ser executados com `mvn spring-boot:run`. Projetos Dart devem utilizar `dart pub get` antes da execução.

## Observações

- O conteúdo possui finalidade acadêmica e didática.
- Alguns exemplos representam etapas intermediárias desenvolvidas em aula.
- Projetos podem exigir configurações locais e banco de dados.
- Credenciais não devem ser publicadas; utilize variáveis de ambiente.
