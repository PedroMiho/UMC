# Programação para Internet

Materiais da disciplina de Programação para Internet.

## Conteúdos

- **Módulo 01 — HTML e CSS:** estrutura, semântica, formulários, layout e responsividade.
- **Módulo 02 — JavaScript:** lógica, DOM, eventos, consumo de APIs e desenvolvimento de CRUD.

Projetos estáticos podem ser executados diretamente no navegador ou com Live Server. Projetos com back-end devem ter suas dependências instaladas conforme o `package.json`.
