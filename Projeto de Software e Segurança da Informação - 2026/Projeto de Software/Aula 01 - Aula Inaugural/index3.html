Introdução

Contextualização rápida do projeto.

  • Qual problema ou necessidade a API resolve
  • Tipo de sistema proposto (cadastro, pedidos, controle, etc.)
  • Quem seria o usuário ou empresa beneficiada
  • Visão geral do funcionamento da API
Dica: explique como se fosse para alguém que não é da área de TI.

Justificativa

  • Motivo da escolha de uma API REST
  • Por que utilizar Spring Boot
  • Vantagens da arquitetura (organização, escalabilidade, integração)
  • Benefícios em relação a controles manuais ou sistemas isolados

Objetivos

  • Objetivo geral do projeto
  • Principais funcionalidades da API
  • O que o sistema permite fazer na prática
  • Problemas específicos que a solução resolve

Desenvolvimento

  • Estrutura do projeto e separação em camadas
  • Tecnologias e ferramentas utilizadas
  • Principais endpoints desenvolvidos
  • Funcionamento da API (requisição e resposta)
  • Possibilidades de integração com front-end ou outros sistemas
Atenção: foque no que foi desenvolvido, não em código.

Conclusão

  • Principais aprendizados do grupo
  • Desafios encontrados durante o desenvolvimento
  • Como esses desafios foram superados
  • Possíveis melhorias e evoluções futuras da API
