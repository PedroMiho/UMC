# Desenvolvimento de Aplicações

Materiais da disciplina de Desenvolvimento de Aplicações, com exemplos desenvolvidos em Dart.

## Conteúdos

- Introdução ao Dart
- Tipos de dados e entrada de informações
- Collections
- Classes e objetos
- Métodos e construtores
- Encapsulamento

Na pasta de cada projeto que contenha `pubspec.yaml`, execute:

```bash
dart pub get
dart run
```
