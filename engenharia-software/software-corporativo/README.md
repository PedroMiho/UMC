# Desenvolvimento de Software Corporativo

Materiais sobre desenvolvimento de aplicações corporativas e APIs REST com Java e Spring Boot.

## Conteúdos

- Métodos HTTP e APIs RESTful
- DTOs e persistência com JPA
- Migrations de banco de dados
- Boas práticas de arquitetura
- Tratamento de erros
- Autenticação e Spring Security

Projetos que possuem `pom.xml` podem normalmente ser executados com:

```bash
mvn spring-boot:run
```

Configure banco de dados e credenciais por variáveis de ambiente.
